# ⏱️ HOUR 1 — "WHAT IS MY JOB?"

**🎯 GOAL = the WHY**, not the tasks. ❌ "Build dashboards" → ✅ "Help managers make faster decisions." Analogy: task = lay bricks; goal = a family lives here safely. *See the family, not the bricks.* Keep asking "Why?" until you hit the business outcome.

**Project vs BAU:** project = temporary, ends, creates something NEW; BAU = ongoing, repeats. (Build a restaurant = project; cook daily = BAU.)

**Manager vs Leader:** Manager = Plan+Track+Coordinate. Leader = Manager + Influence + Decisions + People + Alignment + Business. Coordinator tracks tasks/reports problems/waits/escalates blindly; Leader drives outcomes/solves problems/seeks info/escalates with options. *Ask daily: which side am I on?*

**Ownership ≠ blame.** Blame looks back for a person; ownership looks forward for a fix. Say: *"I'll pick this up and come back Thursday with options."*

**Scope & creep:** IN scope = promised; OUT of scope = the most powerful line you own. Creep = death by a thousand "small changes." Response: `REQUEST → IMPACT → OPTIONS → DECISION`. **Never accept change without understanding impact.**

**Trade-off triangle:** deadline fixed + more scope = something must give (cut scope / add time / add people / add budget / accept risk).

**Success:** finished tasks ≠ success. Success = Scope+Time+Cost+Quality+Risk+People+Stakeholders+VALUE.

**Charter = birth certificate:** WHY (problem+goal) · WHAT (scope/out/deliverables) · HOW (timeline, budget) · WHO (stakeholders, sponsor, lead) · RISK · SUCCESS CRITERIA. Startup order: **WHY → WHO → WHAT → HOW → RISK**.

**🔁 Recall:** goal vs task? which is a goal? the 4 words for "one small extra report" (Request→Impact→Options→Decision)?

# ⏱️ HOUR 2 — "WHO MATTERS?" 👥 STAKEHOLDERS

A stakeholder is anyone who can **influence, is affected by, decides about, or cares about** the project. Formula: **WHO → WHY → POWER → WHAT → HOW.**

**7 hunting questions:** who can STOP / APPROVE / FUND / USE / INFLUENCE / DELAY / is AFFECTED? ⚠️ The most dangerous stakeholder is the one you forgot — usually a blocker (Security) or a quiet crowd (users).

**Power/Interest grid:**
```
HIGH POWER: KEEP SATISFIED | MANAGE CLOSELY
LOW POWER:  MONITOR        | KEEP INFORMED
            LOW INTEREST   | HIGH INTEREST
```
Power = how much ATTENTION; Interest = how much COMMUNICATION. Positions move (a crisis jumps the CEO to "manage closely").

**PACE:** Power · Attention · Communication · Expectations.

**Position vs Interest vs Fear:** "I need this report tomorrow" (position) → "I present to the board Monday" (interest) → "I'll look unprepared" (fear). **Solve the interest, not the position.**

**Expectation gap:** what they think we'll deliver vs what we agreed — close it: write it → read it back → re-confirm on every change.

**Communication matrix:** CEO=outcome/monthly/1-page; Sponsor=risks/weekly/1:1; Team=blockers/daily/standup; Business=requirements/weekly/workshop; Vendor=commitments/weekly/review. One size does NOT fit all.

**Trust:** do what you say · raise bad news early · give credit · protect the team.

# ⏱️ HOUR 3 — "HOW DO WE CONTROL THE PROJECT?"

**WBS:** PROJECT → PHASE → DELIVERABLE → WORKSTREAM → TASK → SUBTASK (break down until one owner, estimable).
**Milestones** = agreed checkpoints (not tasks). Report milestones UP, tasks DOWN.
**Dependencies** — where projects secretly die. Tasks don't kill projects; *waiting* does.
**Critical path** = longest chain of dependent tasks = your real finish date. Move resources *onto* it when threatened.
**RACI** (dinner): R cooks · A owns (exactly ONE) · C advises · I is told.
**RAID:** Risk (may) · Assumption (believe, unconfirmed) · Issue (has) · Dependency (need someone).
**Risk vs Issue:** risk MAY happen (future); issue HAS happened (now).
**Risk management:** Find → Rate (Likelihood×Impact) → Reduce → Watch. Responses: Avoid · Mitigate · Transfer · Accept.
**Issue management:** ISSUE → FACTS → IMPACT → ROOT CAUSE → OPTIONS → OWNER → DEADLINE → (escalate) → RESOLVE.
**Governance:** push each decision to the right level (team → lead → PMO → steering → sponsor → execs).
**Decision log:** kills "I never agreed to that."

# ⏱️ HOUR 4 — "WHAT DO I DO WHEN PEOPLE ARE DIFFICULT?"

**Conflict flow:** STOP REACTING → LISTEN → FIND REAL INTEREST → SEPARATE FACTS FROM OPINIONS → OPTIONS → AGREE → DOCUMENT. Five modes: Avoid · Accommodate · Compete · Compromise · **Collaborate** (default for important things).

**Saying NO — A-C-I-O-R:** Acknowledge + Constraint + Impact + Options + Recommendation. *Say YES to the need, NO to the uncontrolled change.*

**3-option move:** (A) keep scope → move date; (B) keep date → cut scope; (C) keep both → add resources (+risk). Turns a fight into a decision *they* own.

**Difficult-stakeholder library:** Angry→listen+facts · Micromanager→increase visibility · Unresponsive→show impact · Unrealistic→show trade-offs · Constant changer→control change · Blamer→return to facts · Blocker→understand why + escalate · Dominator→acknowledge+redirect · Passive-aggressive→surface kindly · Overloaded→re-prioritize+protect.

**Escalation (responsible, not failure):** ISSUE + FACTS + IMPACT + ACTIONS TAKEN + OPTIONS + RECOMMENDATION + DECISION NEEDED + DEADLINE.

# ⏱️ HOUR 5 — "HOW DO I LEAD?"

**Leading without authority:** TRUST + CREDIBILITY + CLARITY + RELATIONSHIP + DATA = INFLUENCE. Trust before influence — built in drops, lost in buckets; fastest way to lose it is hiding bad news.

**Speak each audience's language:** devs→technical clarity; business→value; managers→progress+risk; execs→outcome+decision; vendors→commitment+accountability.

**Executive comms:** What? So what? Now what? And the so-what rule **F-I-A** (Fact → Impact → Action).

**Meetings:** PURPOSE + AGENDA + RIGHT PEOPLE + DECISION NEEDED + TIME LIMIT + OWNER + NEXT STEPS. No decision + no purpose = should've been an email.

**Decisions:** FACTS → CONSTRAINTS → OPTIONS → TRADE-OFFS → RISK → RECOMMENDATION → DECISION. Indecision is a decision — usually the worst one.

**Change management:** CURRENT → WHY → FUTURE → IMPACT → RESISTANCE → COMMS → TRAINING → ADOPTION. A perfect dashboard nobody uses = a failed project. Reading resistance: don't understand→show; don't agree→discuss; don't know how→train; don't want to→what's in it for them; don't trust→proof+involve; this hurts me→address the fear.

**Recovery:** STOP → GET FACTS → CRITICAL PATH → FREEZE SCOPE → RESOLVE DEPENDENCIES → REALLOCATE → RECOVERY PLAN → ALIGN → EXECUTE → MONITOR → COMMUNICATE. First move is always STOP + get facts.

# ⏱️ HOUR 6 — "CAN I ACTUALLY LEAD?" (SIMULATION)

**Week 12 of 20:** scope +25%, vendor 2 wks late, data quality poor, security delayed, users disagree, BI overloaded, CEO won't move the date, CFO wants more, budget frozen. Run the crisis reflex: **STOP → FACTS → IMPACT → OPTIONS → DECIDE → ACT → MONITOR → COMMUNICATE.**

**Health (RAG):** Scope🔴 Schedule🔴 Cost🟠 Quality🔴 Risk🔴 Resources🟠 Stakeholders🟠 Dependencies🔴 → RED but recoverable. **Recovery:** freeze scope at top-10, parallelize testing+security, reallocate one engineer (no new budget), fast-follow extras, sponsor decision by Friday.

**Role-play lines:** CEO→lead with outcome + one decision; CFO→3 options (A add&slip / B swap / C on-time + fast-follow, recommend C); Tech Lead→empathize, freeze scope, change control, top-2, remove a blocker; Angry user→investigate ("what decision doesn't it support?"); Vendor→demand a written recovery plan.
